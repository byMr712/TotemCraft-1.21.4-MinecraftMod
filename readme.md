# TotemCraft

> **Язык:** Русский · [English](readme.en.md)

Легковесный, настраиваемый Minecraft мод для загрузчика **Fabric 1.21.4**, добавляющий сбалансированный рецепт крафта **Тотема бессмертия** (*Totem of Undying*) в обычном верстаке с полноценным внутриигровым меню настройки через **Mod Menu**.

## Возможности

- **Сбалансированный крафт по умолчанию:** 8 золотых яблок в круг и 1 слеза гаста в центре.
- **Внутриигровой графический конфигуратор (GUI):** Настройка рецепта прямо в игре в аутентичном стиле Minecraft.
- **Поддержка предметов из любых модов:** Встроенный каталог предметов со строкой поиска и пагинацией позволяет установить в любой слот верстака или в результат абсолютно любой предмет из любого установленного мода.
- **Необязательная интеграция с Mod Menu:** При наличии [Mod Menu](https://modrinth.com/mod/modmenu) кнопка настроек автоматически появляется в списке модов. Если Mod Menu отсутствует, мод продолжает работать без ошибок.
- **Динамическое обновление без перезапуска:** Все изменения схемы крафта моментально применяются в игре без перезапуска мира или сервера.
- **Поддержка Vanilla-клиентов:** При установке на сервер игрокам без мода не требуется его устанавливать (рецепт синхронизируется через стандартный протокол крафта).


## Рецепт по умолчанию

В стандартной конфигурации крафт выполняется в сетке 3x3: **8 золотых яблок** по кругу и **1 слеза гаста** строго в центре.

### Схема верстака 3x3

```
+-------------------+-------------------+-------------------+
|  [Золотое яблоко] |  [Золотое яблоко] |  [Золотое яблоко] |
+-------------------+-------------------+-------------------+
|  [Золотое яблоко] |   [Слеза гаста]   |  [Золотое яблоко] |  ===>  [Тотем бессмертия] (1 шт.)
+-------------------+-------------------+-------------------+
|  [Золотое яблоко] |  [Золотое яблоко] |  [Золотое яблоко] |
+-------------------+-------------------+-------------------+
```

### Таблица ингредиентов

| Слот | Предмет | Идентификатор (ID) | Количество |
|:---:|---|---|:---:|
| 1-3, 4, 6, 7-9 | **Золотое яблоко** (*Golden Apple*) | `minecraft:golden_apple` | 8 шт. |
| 5 (Центр) | **Слеза гаста** (*Ghast Tear*) | `minecraft:ghast_tear` | 1 шт. |
| **Результат** | **Тотем бессмертия** (*Totem of Undying*) | `minecraft:totem_of_undying` | 1 шт. |


## Графическое меню настройки (GUI)

При установленном моде [Mod Menu](https://modrinth.com/mod/modmenu) перейдите в **Главное меню ➔ Моды ➔ TotemCraft ➔ Настройки**:

- **Интерактивная сетка верстака 3x3:** Кликните на любой слот верстака, чтобы выбрать его для редактирования (слот подсветится золотой рамкой).
- **Слот результата и регулировка количества:** Выберите слот результата, чтобы изменить получаемый предмет и его количество (кнопки `+` / `-` от 1 до 64).
- **Полнотекстовый поиск предметов:** Введите в строку поиска название предмета на русском/английском или его ID (например, `apple`, `diamond`, `botania:mana_pearl`).
- **Каталог всех зарегистрированных предметов:** Сетка 8x4 с удобной пагинацией отображает все предметы игры и любых сторонних модов. Кликните по предмету в каталоге, чтобы мгновенно назначить его в активный слот.
- **Быстрые действия:**
  - `Очистить слот` — удаляет предмет из выбранного слота (делает его пустым).
  - `Заполнить 8` — заполняет все 8 внешних слотов предметом из активного слота.
  - `Очистить все` — очищает всю сетку верстака.
  - `Рецепт: ВКЛЮЧЕН / ВЫКЛЮЧЕН` — мгновенное включение или отключение рецепта.
  - `По умолчанию` — сброс к 8 золотым яблокам + слеза гаста.

## Системные требования

- **Minecraft:** `1.21.4`
- **Загрузчик модов:** [Fabric Loader](https://fabricmc.net/) `0.16.0+`
- **Java:** `Java 21` или новее
- **Библиотека:** [Fabric API](https://modrinth.com/mod/fabric-api) (рекомендуется)
- **Опционально:** [Mod Menu](https://modrinth.com/mod/modmenu) (для открытия меню настроек в игре)


## Установка

### Для одиночной игры / Клиента
1. Установите [Fabric Loader](https://fabricmc.net/use/) для Minecraft **1.21.4**.
2. Поместите `Fabric API`, `Mod Menu` (по желанию) и `TotemCraft-1.0.0.jar` в папку `.minecraft/mods/`.
3. Запустите игру.

### Для сервера (Dedicated Server)
1. Установите Fabric на ваш сервер Minecraft 1.21.4.
2. Поместите `Fabric API` и `TotemCraft-1.0.0.jar` в папку `mods/` на сервере.
3. Перезапустите сервер.

## Сборка проекта

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/byMr712/TotemCraft-MinecraftMod.git
   cd TotemCraft-MinecraftMod
   ```

2. Соберите проект через Gradle:
   - **Linux / macOS:** `./gradlew clean build`
   - **Windows:** `.\gradlew.bat clean build`

3. Скомпилированный файл будет сохранен в:
   ```
   build/libs/TotemCraft-1.0.0.jar
   ```
